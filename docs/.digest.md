# Project Digest — libras-cv

## STACK
- Language: Python 3.x
- CV: opencv-python >= 4.8.0, mediapipe >= 0.10.0
- ML Phase A: scikit-learn >= 1.3.0 (SVM, RBF kernel)
- ML Phase C: torch >= 2.1.0, torchvision >= 0.16.0 (EfficientNet-B0)
- Data: numpy, pandas, Pillow, tqdm
- Plotting: matplotlib, seaborn
- Dataset: kaggle >= 1.5.16

## ARCHITECTURE PATTERN
- Flat-script pipeline (no framework, no DI container)
- Phase A: webcam → MediaPipe landmarks → wrist-normalize → SVM → label
- Phase C: webcam → MediaPipe bbox crop → EfficientNet-B0 → label
- Training: notebooks (local Phase A, Colab Phase C); Inference: demo.py (local CPU)

## KEY CONSTRAINTS
- REQUIRED: Normalize landmarks wrist-relative before SVM training/inference
- REQUIRED: Save hand-crop JPEGs (not full frames) in collect_data.py
- PROHIBITED: Committing data/ or models/ to git
- PROHIBITED: Opening a real camera in automated pytest runs
- PROHIBITED: Training EfficientNet-B0 on local AMD GPU (use Colab T4)

## TEST COMMANDS
- Unit: `pytest src/`
- Coverage: `pytest --cov=src --cov-report=term-missing src/`
- Visual smoke: `python demo.py`
- Min coverage (src/): 70% global, 80% landmark normalization
