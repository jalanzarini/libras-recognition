## ARCHITECTURE PATTERN
- Flat scripts; implemented: webcam collection → clean hand-crop JPEG + landmark sidecar → wrist-relative features → RBF SVM, plus live webcam inference in `demo.py`.
- Phase A notebook, shared utility, and local inference entrypoint implemented; Phase C EfficientNet remains absent.
- Latest `data/personal-updated` run: 1,050 paired samples; selected candidate scored 0.9666 macro-F1 and 96.67% accuracy on the shared stratified holdout, vs. 0.0403 and 11.43% for the previous model; final model fit used all samples.
- Historical legacy dataset run: 920 accepted, 130 rejected, 89.13% holdout accuracy; class C had 18 accepted samples.
